# WBUK website

Static website for WBUK (Whitebox UK), a UK hospitality procurement and operational improvement consultancy.

- `index.html` home page
- `procurement-services/` procurement services page
- `book-a-consultation/` enquiry form (sends to Formspree)
- `assets/img/` photos
- `_headers`, `.htaccess` security headers (used by Cloudflare Pages, Netlify or Apache hosting; GitHub Pages ignores them)
- `robots.txt`, `sitemap.xml`, `llms.txt`, `.well-known/security.txt` search, AI and security files

See SECURITY-AND-EDITING-GUIDE.md for editing and launch notes.
